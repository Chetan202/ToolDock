Privacy, plainly.

Last updated: October 24, 2026

ToolDock is built around a simple principle: your data is yours. The extension does not require a ToolDock account, and its own saved prompts, settings, and chat index are kept locally in your browser.

The short version

ToolDock does not collect or send your ToolDock data to a ToolDock-controlled server. Information used by the extension stays in local browser storage unless you choose an action that opens a supported AI provider or exports a file.

What ToolDock stores locally

ToolDock stores the following data in your browser using chrome.storage.local:

  • Theme preference — the visual theme selected for a site.
  • Saved prompts — the prompts you add to your personal prompt library.
  • Chat index — chat titles from ChatGPT, Claude, Gemini, and Grok used to power cross-site search.
  • Interface preferences — panel positions, dismissed notices, and other UI state.
  • Wellness reminder settings — reminder preferences you choose.

This information is stored locally and can be removed when you clear extension data or uninstall ToolDock.

What ToolDock does not collect

  • Your name, email address, or other identifying details as part of the extension’s normal operation.
  • Analytics about how you use the extension.
  • Payment or financial information.
  • An API key for use by the Claude token counter in persistent extension storage; any key entered for this purpose is intended to remain in memory only.

When you use an AI provider’s website, that provider handles the conversation itself under its own policies. ToolDock does not control those services.

Permissions and why they are used

ToolDock requests Chrome extension permissions to power its browser features. Each permission should be used only for its stated purpose.

PermissionPurpose
activeTabRead the active AI page when you use chat or page tools.
tabsOpen destination AI sites in new tabs for Switch AI.
scriptingRun locally bundled scripts on supported pages; ToolDock does not execute remote code.
storageSave prompts, preferences, themes, and the local chat index.
unlimitedStorageKeep the chat index without quickly hitting Chrome’s default storage limit.
downloadsSave exported conversations and other files to your device when you request an export.
offscreenSupport screenshot processing and clean export previews where needed.
Host permissionsAllow the extension’s features to work on ChatGPT, Claude, Gemini, and Grok pages.

Third-party services

ToolDock does not use a ToolDock-hosted analytics or advertising service. When a feature opens an AI site or you choose to share or continue a conversation with another provider, your use of that provider is governed by its own privacy policy.

Remote code

ToolDock is intended to run code bundled in the extension package rather than fetch executable code from an external server at runtime.

Children’s privacy

ToolDock is not directed at children under 13 and is not designed to collect personal data from children.

Changes to this policy

If this policy changes materially, the date at the top of this page will be updated and, where possible, the change will be noted in the Chrome Web Store release notes.
